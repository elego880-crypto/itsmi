# Участие в разработке ИТСМИ

Спасибо за интерес к проекту. Мы рады любому вкладу — будь то исправление бага, новая функция или улучшение документации.

---

## С чего начать

1. **Форкни** репозиторий
2. **Склонируй** свой форк локально
   ```bash
   git clone https://github.com/your-username/itsmi.git
   cd itsmi
   ```
3. **Установи** зависимости и настрой окружение
   ```bash
   npm install
   cp .env.example .env
   # заполни .env своими данными
   ```
4. **Создай ветку** для своих изменений
   ```bash
   git checkout -b feat/название-фичи
   # или
   git checkout -b fix/название-бага
   ```

---

## Правила именования веток

| Тип | Формат |
|-----|--------|
| Новая функция | `feat/короткое-описание` |
| Исправление бага | `fix/короткое-описание` |
| Документация | `docs/короткое-описание` |
| Рефакторинг | `refactor/короткое-описание` |
| Стили/UI | `style/короткое-описание` |

---

## Коммиты

Используем [Conventional Commits](https://www.conventionalcommits.org/ru/):

```
feat: добавить поиск по каналам
fix: исправить двойную отправку формы
docs: обновить инструкцию по деплою
style: выровнять карточки в ленте
refactor: вынести renderPost в отдельный модуль
```

---

## Как отправить Pull Request

1. Убедись что проект запускается без ошибок
2. Запушь ветку в свой форк
   ```bash
   git push origin feat/название-фичи
   ```
3. Открой Pull Request в основной репозиторий
4. Заполни описание: **что изменил** и **зачем**
5. Дождись ревью

## Что не принимаем

❌ Изменения, ломающие существующий функционал без обсуждения  
❌ Добавление тяжёлых фреймворков (React, Vue и т.д.) — проект намеренно на Vanilla JS  
❌ Коммиты с кодом, который не запускается
